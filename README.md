# Desert Serenity Studio

Create a premium, minimalist, conversion-focused landing page/homepage for an Abu Dhabi-based desert safari company.

The website will be used for paid advertising through Google Ads, Facebook and Instagram, so the homepage must be visually impressive while also making it extremely easy for visitors to understand the services and submit an enquiry or contact the company through WhatsApp.

IMPORTANT TECHNICAL REQUIREMENT

Build this as a:

Vite + React + JavaScript + JSX + Tailwind CSS

project.

Do NOT use Next.js.

Do NOT use TypeScript.

Do NOT create .js or .jsx files.

Do NOT use any Next.js-specific features such as:

next/image

next/link

Next.js App Router

Server Components

Next.js metadata APIs

Next.js-specific routing

Use standard React, JSX and browser APIs.

The project must be a normal Vite project that can run with:

npm install
npm run dev


BUSINESS

The company is based in Abu Dhabi, UAE and specializes in desert safari experiences.

The website should position the company as a professional, premium and trustworthy desert experience provider.

The website should not feel like a cheap generic tourism website.

The desired feeling is:

Modern Arabian Luxury

Think:

Luxury hospitality

Arabian desert

Cinematic travel

Modern editorial design

Warm and sophisticated

Minimal but visually rich

PRIMARY WEBSITE GOALS

The homepage has four main goals:

1. Create a strong first impression

When someone arrives from Google, Facebook or Instagram advertising, the website should immediately feel professional and trustworthy.

2. Explain the services

Visitors should quickly understand what desert safari experiences are available.

3. Build desire and trust

Use beautiful photography, concise storytelling and reviews.

4. Generate leads

Visitors should be able to:

Submit an enquiry form

Click WhatsApp

Contact the company easily

Do not make the visitor search for how to book.

RESPONSIVE DESIGN

The website must be genuinely responsive.

Test:

1440px+

1280px

1024px

768px

480px

414px

390px

375px

320px

Mobile should not simply be a scaled-down desktop layout.

At mobile widths:

Navigation becomes a hamburger menu

Experience cards stack vertically

Multi-column layouts become single-column

Buttons remain easy to tap

Typography scales fluidly

Images remain correctly cropped

Form fields become full width

No horizontal scrolling

No overlapping text

No overflowing buttons

No fixed-width elements that break the layout

Do not solve responsiveness simply by applying overflow-x-hidden.

Fix the actual layout issues.
